# Landingpage MVP

Static landingpage for the first Aethelgard pilot outreach wave.

Preview locally by opening:

```text
marketing/landing/index.html
```

Boundaries:

- no build step
- no external fonts
- no CDN
- no tracking scripts
- no cookies
- no customer data
- contact placeholder stays `TODO_CONTACT` until the owner approves a real address

Run the marketing safety check before publishing:

```powershell
python scripts/check_marketing_claims.py
```

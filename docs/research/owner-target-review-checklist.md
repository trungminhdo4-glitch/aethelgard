# Owner Target Review Checklist

Before sending any message:

- Website noch aktuell?
- Kontaktkanal oeffentlich und allgemein?
- Firma passt zum ICP?
- Kein personenbezogener Kontakt verwendet?
- Nachricht enthaelt engen Aethelgard-Claim?
- Keine Compliance-/Audit-Garantie?
- CTA klar?
- Keine sensiblen Daten angefragt?
- Sample-Pack-Regeln angehaengt/verlinkt?
- Follow-up-Datum gesetzt?
- Kein LinkedIn-/Xing-Profil als Quelle oder Kontaktweg verwendet?
- Kein Versand automatisiert?

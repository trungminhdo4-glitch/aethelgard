# AethelGard Product Positioning

## Verified Product Kernel

AethelGard is a local evidence-triage engine for Security/NIS-2-style documents. It turns
text or PDF content into structured evidence reports by combining keyword matching,
bounded chunk extraction, deterministic scoring, JSON/Markdown report generation, and
synthetic-corpus evaluation.

It is not an agent governance platform, workflow orchestrator, sales automation product,
legal advisor, audit provider, or full NIS-2 compliance system.

## Strongest First Use Case

The strongest first use case is a local document pre-review workflow for SMEs, MSPs, and
security/compliance advisors. The useful promise is: faster evidence triage with traceable
citations, visible gaps, and measurable false positives/false negatives.

## Best First ICP

Small security consultancies, IT compliance advisors, or managed service providers serving
NIS-2-affected SMEs are the best first ICP. They understand the document-review pain,
can provide non-sensitive sample documents, and can judge whether the workflow saves time.

## Pilot Offer

Name: AethelGard Evidence Triage Pilot

Scope: In 7 to 14 days, run the local CLI against synthetic and customer-approved
non-sensitive documents, produce JSON/Markdown evidence reports, compare output against
agreed review expectations, and document false positives/false negatives.

Boundaries:

- No legal advice.
- No certification claim.
- No external API upload.
- No SaaS or multi-tenant data processing.
- No processing of secrets, credentials, private logs, or production datasets.
- Human review remains required.

## Monetization Notes

The fastest monetization path is a paid pilot or done-with-you setup for document evidence
triage. A SaaS platform is premature until customer onboarding, data-handling, and
evaluation metrics have been validated in at least one real pilot.

# Pilot License Notice

This is a technical pilot notice, not a final legal contract. It must be reviewed by
qualified legal/privacy counsel before any real customer delivery.

The intended pilot posture is:

- No source access unless the owner explicitly grants it in a separate agreement.
- No redistribution of the artifact, reports, screenshots, or generated outputs.
- No reverse engineering, decompilation, or attempt to bypass packaging controls.
- Time-limited pilot use only.
- No production use without a separate written agreement.
- No compliance guarantee, certification, audit opinion, legal advice, or regulatory
  assurance.
- Human review is required before using outputs for decisions or external handover.
- Customer documents stay local to the approved pilot environment.
- Support bundles are redacted by default and must be reviewed before sharing.

For first conversations, prefer screen-share and redacted synthetic demo materials.
For customer-side execution, use only a reviewed artifact with a signed NDA or pilot
license.

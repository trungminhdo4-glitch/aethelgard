1. Problem: first-pass evidence review is slow and repetitive.
2. Sample pack: show `tests/fixtures/customer_like_nis2/` as synthetic, non-customer data.
3. CLI run: execute `triage` against the sample pack.
4. Report: show Markdown/JSON outputs and bounded snippets.
5. Human review: show `docs/human-review-checklist.md`.
6. Data handling: show allowed inputs, exclusions, retention, and deletion flow.
7. Pilot scope: show `docs/pilot-scope.md`.
8. CTA: ask for a redacted, non-sensitive sample pack for a small controlled pilot.

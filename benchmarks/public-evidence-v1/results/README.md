# Benchmark Result Snapshot

2026-07-14. Full generated reports and hash-chained ledgers remain under the local
`reports/public-evidence-v1-final-a` and `reports/public-evidence-v1-final-b` output
folders and are not benchmark fixtures.

The result is measured against `provisional_internal_reference` labels on a small,
project-created lab set. It is not an expert gold standard, external validation, or a
real-world accuracy claim.
